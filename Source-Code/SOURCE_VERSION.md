# VMEC-lyh 源码版本

本目录中的 [VMEC-lyh](VMEC-lyh/) 是从 VMEC-docs 的 `83b0d342cc575171bce6ca6502ee6ccd4b93a06f` 导出的源码快照。该提交添加了 NCSX 数据，源码对应 `a435182006ef765e677c67a84f989198dcb51111`，也是本仓库 NCSX 维护版 WOUT 的计算版本。

VMEC-lyh 基于 STELLOPT 的 VMEC2000。原始基准版本为 `780f5db557eacc7ca1160f4ca5a10a80922e4f26`。迁移保留了源码、构建文件和许可证说明。[STELLOPT 上游基准](https://github.com/PrincetonUniversity/STELLOPT/tree/780f5db557eacc7ca1160f4ca5a10a80922e4f26)

源码根目录提供 [STELLOPT 许可证](VMEC-lyh/LICENSE.txt)。随代码附带的第三方例程保留其各自文件中的版权与许可声明。
