# NCSX 自由边界 WOUT 数据对比

仓库中的[原版 WOUT](wout_ncsx_c09r00_free.nc)和新增的[VMEC-lyh WOUT](wout_ncsx_c09r00_free_additional_lyh.nc)均满足原 FTOL = 1e-12。使用[原版输入](input.ncsx_c09r00_free)和[新版实际运行输入](input.ncsx_c09r00_free_additional_lyh)。新版输入的 INDATA 内容与原版相同，另显式写出 ADDITIONAL_LYH 的默认值。两次运行使用同一 mgrid_c09r00.nc 和 4 个 MPI 秩，每秩 1 线程。最终 NS = 99，NFP = 3，MPOL = 11，NTOR = 6。计算采用仿星器对称的自由边界配置。VMEC-lyh 来自提交 [a435182](../../Source-Code/SOURCE_VERSION.md)，采用默认求解路径。

### 自由边界复核

固定各自 WOUT 重构的谱状态，完整刷新 NESTOR。新版的显式默认输入与省略附加组的复算，其 WOUT 数值字段逐元素一致。内部 R、Z 残差按原版常规口径计算，LCFS 的离散力残差 FEDGE 和总压跳跃单独统计。总压跳跃 RMS 使用原生真空角网格的表面积权重。

| 诊断量 | 原版 VMEC | VMEC-lyh | 绝对差 |
| --- | ---: | ---: | ---: |
| 刷新后的 R 力残差 | 9.93858452584e-13 | 9.93649029453e-13 | 2.094e-16 |
| 刷新后的 Z 力残差 | 2.26176840499e-13 | 2.25929811775e-13 | 2.470e-16 |
| 刷新后的 λ 残差 | 1.6255310956e-13 | 1.62453168867e-13 | 9.994e-17 |
| FEDGE | 4.29373554042e-11 | 4.29191365582e-11 | 1.822e-14 |
| 总压跳跃 RMS（Pa） | 3985.29395192 | 3985.29719472 | 3.243e-03 |
| 总压跳跃绝对值采样峰值（Pa） | 20126.5394926 | 20126.5872617 | 4.777e-02 |
| 重构边界 Bn RMS（mT） | 3.81019547316 | 3.81019712748 | 1.654e-06 |
| 重构边界 Bn 绝对值采样峰值（mT） | 17.7656309947 | 17.7656425151 | 1.152e-05 |

Bn 由线圈场加虚拟套管重构的等离子体场后投影至 LCFS 外法向得到。两份解使用相同的矢势积分方法，积分源网格为每场周期 84 × 108，诊断采样网格为每场周期 28 × 36。边界诊断用于比较两版在同一离散口径下的结果。
